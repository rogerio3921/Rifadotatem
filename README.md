# Rifa do Tatem — demonstração

Projeto de testes do aplicativo Rifa do Tatem.

## Publicação

1. Extrair `rifa-do-tatem-github-pages.zip`.
2. Enviar `index.html` e `capa.png` à raiz deste repositório, sem pastas intermediárias.
3. Em Settings > Pages, selecionar Deploy from a branch, `main` e `/ (root)`; salvar.
4. Aguardar o deploy e acessar `https://rogerio3921.github.io/Rifadotatem/`.

**Atenção:** demonstração apenas, dados no armazenamento local do navegador; sem autenticação, pagamentos reais ou banco de dados compartilhado.
